<h1 align="center">QLauncher</h1>

<p align="center">
  <b>Современный, быстрый и кроссплатформенный лаунчер для Minecraft на базе Avalonia UI (.NET 10)</b>
</p>

<p align="center">
  <i>Интерфейс в стиле Fluent Design, высокая отзывчивость, поддержка Linux / Windows / macOS и полезные встроенные утилиты для комфортной игры.</i>
</p>

## Ключевые возможности

### Интерфейс и кастомизация
* **Тёмная и светлая темы** с поддержкой акцентных пресетов: Sapphire, Amethyst, Emerald, Rose, Amber, а также тематических пресетов Nether, End и Sift со встроенными обоями.
* **Современная навигация:** Кастомный TitleBar, быстрое переключение между вкладками (Главная, Сборки, Моды, Скриншоты, Консоль) и быстрый доступ к папкам игры.
* **Никаких системных окон:** Кастомные всплывающие Toast-уведомления и диалоги в едином стиле интерфейса.
* **3D-превью скина:** Встроенный кроссплатформенный 3D-просмотрщик скинов (поддержка classic/slim, вращение мышью, зум и сохранение PNG).
* **Звуковые эффекты UI:** Процедурная генерация звуков на лету без лишних аудиофайлов.

### Управление сборками и модами
* **Создание сборок в один клик:** Поддержка Vanilla, Fabric, Quilt (а также Forge/NeoForge), автоматическая установка Sodium/Iris.
* **Каталог модов:** Поиск и установка модов, ресурспаков, шейдеров и датапаков из Modrinth и CurseForge, избранное и проверка обновлений.
* **Порядок в модах и мирах:** Включение/отключение и удаление модов, создание Zip-бэкапов миров и быстрое восстановление.
* **Обмен с друзьями:** Импорт (`.mrpack` / `.zip`, включая Drag & Drop) и экспорт сборок, а также создание ярлыков запуска (`.lnk` на Windows, `.desktop` на Linux).

### Стабильность и обход блокировок
* **Зеркала загрузки (BMCLAPI / официальные):** Автоматическая проверка доступности источников и переключение зеркал при сбоях.
* **Умная настройка Java:** Автоматическая загрузка и подбор совместимой версии OpenJDK.
* **Лента новостей:** Поддержка зеркал для ленты новостей проекта.

### Мониторинг и Discord
* **Статус серверов:** Отслеживание онлайна, версии и пинга игровых серверов в реальном времени.
* **Игровое время:** Подсчёт времени и количества запусков для каждой сборки.
* **Discord RPC:** Отображение статуса игры в Discord с возможностью скрыть IP-адрес сервера.

## Сборка и запуск

### Что понадобится:
* **Linux**, **Windows 10 / 11** или **macOS**
* Установленный **.NET 10.0 SDK**

Выполните следующие команды в терминале для запуска проекта из исходников:

```bash
# Клонируем проект
git clone https://github.com/seasharpic/qlauncher.git

# Переходим в папку с лаунчером
cd qlauncher

# Собираем и запускаем приложение
dotnet build QLauncher.sln
dotnet run
```

## Сборка готового бинарника (Publish)

### Linux (x64)
```bash
dotnet publish -c Release -r linux-x64 --self-contained true -p:PublishSingleFile=true
```

### Windows (x64)
```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

### macOS (Apple Silicon / Intel)
```bash
dotnet publish -c Release -r osx-arm64 --self-contained true -p:PublishSingleFile=true
# или -r osx-x64
```
