<h1 align="center">QLauncher</h1>

<p align="center">
  <b>Современный, стильный и быстрый кастомный лаунчер для Minecraft на базе WPF (.NET 8)</b>
</p>

<p align="center">
  <i>Интерфейс в стиле Fluent Glassmorphic UI, высокая отзывчивость и полезные встроенные утилиты для комфортной игры.</i>
</p>


---

## Ключевые возможности


### Интерфейс и кастомизация
* **Красивая тёмная тема** с поддержкой сочных акцентных цветов: Сапфир, Аметист, Изумруд, Роза и Янтарь.
* **Современная навигация:** Удобный минималистичный TitleBar и быстрое переключение между вкладками: Главная, Моды, Сборка, Скриншоты и Консоль.
* **Никаких старых окон:** Кастомные всплывающие Toast-уведомления вместо серых стандартных диалогов Windows.
* **Приятный звук:** Встроенные звуковые эффекты UI, которые генерируются процедурно на лету и не требуют скачивания лишних аудиофайлов.

### Управление сборками и модами
* **Создание сборок в один клик:** Устанавливайте Vanilla, Fabric или Forge прямо из выпадающего списка версий.
* **Порядок в модах:** Удобный менеджер для включения, отключения, удаления модификаций и быстрого перехода в рабочую папку.
* **Безопасность миров:** Создание резервных Zip-бэкапов ваших сохранений и безопасное удаление старых миров.
* **Обмен с друзьями:** Быстрый импорт и экспорт готовых сборок в один архив, а также создание ярлыков запуска прямо на рабочий стол.

### Стабильность и обход блокировок (Без VPN)
* **BMCLAPI Зеркала:** Автоматический обход блокировок серверов Fabric Meta со стороны провайдеров. Лаунчер работает стабильно без сторонних VPN-сервисов.
* **Умная настройка Java:** Автоматическая загрузка нужной версии OpenJDK (Java 8, 17 или 21) с зеркал Azul Zulu CDN и BMCLAPI.
* **Лента новостей:** Резервные узлы для зеркалирования новостей из Telegram-канала проекта.

### Мониторинг и Discord
* **Статус серверов:** Живой трекинг онлайна и пинга до игровых серверов в реальном времени.
* **Игровое время:** Лаунчер считает, сколько минут вы провели в конкретной сборке.
* **Discord RPC:** Красивый статус «Играет в...» в вашем профиле Discord с возможностью скрыть IP-адрес сервера из соображений приватности.

## Сборка и запуск

### Что понадобится:
* Операционная система **Windows 10 / 11**
* Установленный **.NET 8.0 SDK**

Выполните следующие команды в терминале для запуска проекта из исходников:

```bash
# Клонируем проект к себе на ПК
git clone https://github.com

# Переходим в папку с лаунчером
cd QLauncher

# Собираем и запускаем приложение
dotnet build
dotnet run
```

---

## Создание готового EXE (Publish)

Если вы хотите собрать один независимый автономный `.exe` файл приложения без лишнего мусора, выполните команду:

```bash
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```
